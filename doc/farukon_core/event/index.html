Event system: defines messages passed between components. Uses trait-based polymorphism to handle MARKET, SIGNAL, ORDER, FILL uniformly.

Components (DataHandler, Strategy, Portfolio, Execution) communicate via events. Events are sent through channels and processed in FIFO order. This decouples components and enables modularity and speed.
