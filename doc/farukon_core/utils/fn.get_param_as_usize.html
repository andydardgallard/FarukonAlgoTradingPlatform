Expand description

Helper function to extract a parameter value as usize from the strategy settings. It checks for the parameter in the map, verifies it’s a number, and converts it to usize.

§Arguments

  • params - The map of strategy parameters.
  • name - The name of the parameter to extract.

§Returns

  • anyhow::Result<usize> - The parameter value as usize or an error.
