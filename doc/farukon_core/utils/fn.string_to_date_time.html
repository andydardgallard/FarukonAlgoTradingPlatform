pub fn string_to_date_time(
    string: &String,
    format: &str,
) -> Result<DateTime<Utc>>
Expand description

Converts a string representation of a date and time into a chrono::DateTime<chrono::Utc>. This function uses chrono::NaiveDateTime::parse_from_str to parse the input string according to the provided format, then converts the resulting NaiveDateTime to a DateTime<Utc>.

§Arguments

  • string - The date-time string to parse (e.g., “2025-07-08 15:30:00”).
  • format - The expected format of the input string (e.g., “%Y-%m-%d %H:%M:%S”).

§Returns

  • anyhow::Result<chrono::DateTime<chrono::Utc>> - The parsed UTC date-time on success, or an error if parsing fails.
