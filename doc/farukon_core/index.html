farukon_core/src/lib.rs Core library entry point. Re-exports all public modules for use by Farukon_2_0 and strategy_lib.

This file also defines the VTable for dynamic strategy loading. The VTable allows C-compatible interfaces to Rust DataHandler, enabling dynamic linking.
