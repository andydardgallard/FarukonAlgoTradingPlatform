## Project Overview

Farukon is a high-performance, Rust-based algorithmic trading platform for ultra-low-latency backtesting, multi-strategy optimization, and real-time execution. Built with zero-copy FlatBuffers, SIMD-accelerated calculations, and a multi-threaded event-driven architecture.

- **Repository:** https://github.com/andydardgallard/FarukonAlgoTradingPlatform
- **Language:** Rust (primary), Python (visualization scripts)
- **License:** MIT

## Architecture Overview

```
CLI (Farukon_2) → settings.rs (config deserialization)
  ├─ mode=Optimize → OptimizationRunner (optimizers.rs)
  │   ├─ GridSearch → GridSearchOptimizer (optimization.rs)
  │   ├─ Genetic  → GeneticAlgorythm (optimization.rs)
  │   │   ├─ evaluate_population() → backtest (threaded)
  │   │   └─ save results to CSV
  │   └─ [LSHADE_RSP — to be added]
  ├─ mode=Debug   → single backtest
  └─ mode=Visual  → equity curve generation

Data pipeline:
  Tickers_fbs/ (.soa.bin + .soa.idx) → DataEngine → DataHandler trait → Strategy
```

**Optimizer selection:** `OptimizerType` enum in `farukon_core/src/settings.rs` — tagged JSON enum with serde deserialization. Dispatch in `Farukon_2/src/main.rs` via match.

## Build & Run Instructions

```bash
# Build (release)
cargo build --release

# Build strategy plugin
cargo build -p strategy_lib --release

# Run backtest/optimization
cargo run --release -- --config portfolios/MA_cross_Portfolio.json

# Run all tests
cargo test --workspace

# Run specific crate tests
cargo test -p farukon_core

# Python visualization (from python/)
python visual.py <path_to_results_dir>
python optresults_handler.py -f <csv_file> --mode visual --dimension 2D --yaxis set
```

## Known Constraints & Limitations

1. **`workspace.authors` warning:** `Cargo.toml` has `authors = ["Andy Dar"]` at workspace level — this key is unused in workspace manifests. Harmless, kept for metadata.
2. **No optimizer trait:** `GridSearchOptimizer` and `GeneticAlgorythm` are concrete structs without a shared `Optimizer` trait. Adding a new optimizer requires modifying the `OptimizerType` enum, adding match arms in `main.rs`, and adding methods to `OptimizationRunner`.
3. **instruments_info.json modified:** Local uncommitted changes exist (likely from previous task).
4. **Python GA coupling:** `python/plot_portfolio_genetic_results.py` reads GA-specific CSV (`ga_optimization_results.csv`). LSHADE-RSP needs its own counterpart.
5. **Tests are minimal:** Only 8 unit tests in `farukon_core` (indicators + utils). No integration tests for optimization or backtesting.
6. **No CI/CD:** No GitHub Actions or other CI pipelines found in the repo.
